# hololive Dreams Companion Toolkit — feature reference

Use the hololive Dreams companion toolkit workspace to move between collection notes, session records, and profile groups. The section map below gives each part a clear place in the project.

| Section | Description |
|---|---|
| Collection notes | A dedicated section for collection notes and the configuration details associated with that area. |
| Session records | Session and activity information grouped by the task or context it belongs to. |
| Profile groups | Related settings collected into named groups for a clearer configuration workflow. |

The project page follows the same section structure.
